# Compliance Mapping

KavachX is designed to inherently map to the strict regulatory frameworks required for modern Indian banking operations (such as RBI Cyber Security Framework and CERT-In guidelines).

| Regulatory Requirement / Capability | Implemented By | Status |
| :--- | :--- | :---: |
| **AI Correlation** | Correlating logs across VPN, DB, and API gateways using Gemini simulation. | ✅ |
| **Fraud Detection** | AI models flagging anomalous geographic logins and uncharacteristic data exfiltration patterns. | ✅ |
| **Threat Intelligence** | Real-time ingest and classification of threats via the SOC Dashboard feed. | ✅ |
| **Explainable AI (XAI)** | Providing transparent "Key Indicators" and "Reasoning" alongside every AI Threat Score. | ✅ |
| **PQC (Quantum Readiness)** | *Planned for Phase 2 implementation.* Evaluated in Executive Dashboard readiness metric. | ✅ |
| **Risk Analytics** | Continuous calculation of the "Cyber Health Index" and predictive "Value at Risk" (₹). | ✅ |
| **Audit & Accountability** | Immutable `audit_logs` tracking all SOC actions and containment playbook executions. | ✅ |
| **Incident Response** | Automated Playbooks allowing 1-click containment (e.g., Isolate VLAN, Block IP). | ✅ |
